
# 📍 Buscador de Endereço por CEP

Projeto desenvolvido para praticar consumo de API REST e manipulação de estados no React. A aplicação permite buscar um endereço completo a partir de um CEP, utilizando a API pública ViaCEP.

## 📚 Conceitos praticados

- Consumo de APIs REST (fetch, requisições HTTP GET)
- Gerenciamento de estados com React (useState)
- Manipulação de formulários e eventos no Front-end
- Tratamento de erros e validação de resposta assíncrona
- Estilização responsiva com CSS puro
- Deploy de aplicações Front-end (Vercel)

## 💻 Sobre o projeto

A proposta foi criar uma aplicação simples e funcional para consulta de endereços. Através de uma interface limpa e estilizada com CSS personalizado, o utilizador digita um CEP e recebe as informações de logradouro, bairro, cidade e estado correspondentes, consumindo a API pública ViaCEP em tempo real.

## 🔍 Funcionalidades

- Busca de endereço a partir do CEP informado
- Exibição de logradouro, bairro, cidade e estado
- Tratamento de erros para CEP inválido ou não encontrado
- Comunicação assíncrona com a API ViaCEP
- Interface responsiva e adaptada para dispositivos móveis

## 🚀 Como executar

### Pré-requisitos
- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)

### 1. Clone o projeto

```bash
git clone https://github.com/gmclaraa/cep_finder.git
cd cep_finder
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Execute o projeto
```bash
npm run dev
```

### 4. Acesse
Abra no navegador:
```text
http://localhost:5173
```
